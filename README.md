## 启动

双击 `Start.vbs`。也可以在本目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\pet.ps1
```

需要 Windows 10/11、Windows PowerShell 5.1、Python 3.10+，以及已登录的 Codex 桌面应用。先通过本页 **Code → Download ZIP** 下载并解压，然后双击 `Start.vbs`。优先使用 Codex 已安装的 Python 运行时；找不到时使用 PATH 中的 Python。无需安装 Python 第三方包。`ExecutionPolicy Bypass` 仅用于该启动进程，不修改系统设置。

拖动角色或卡片移动。右键可调整大小、关闭动画、收起面板和退出；Esc 也可退出。系统托盘显示白龙娘图标：右键可“显示桌宠”“隐藏桌宠”或退出，双击图标也可重新显示。桌宠右键菜单也提供“隐藏桌宠”。隐藏后继续采集额度和任务状态，提醒不会自行弹出桌宠；恢复时显示最新状态并保留位置。下次启动默认显示。Windows 可能将图标放进托盘的隐藏图标区域。位置和设置保存在 `runtime/settings.json`。重复启动不会多开。不会注册开机启动或更换现有官方桌宠。

## 随 Codex 启动

右键菜单勾选“随 Codex 启动”即可启用，取消勾选即可关闭。也可以运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Set-Autostart.ps1`，关闭时追加 `-Disable`。默认不启用。

启用后只在当前 Windows 用户的启动文件夹创建一个快捷方式，登录 Windows 时启动隐藏监测器。它每 2 秒检查本机 Codex 桌面进程，在 Codex 启动时启动桌宠；若 Codex 已运行，启用后立即启动桌宠。不调用网络或账户接口，不将 Codex CLI 后台进程或普通 ChatGPT 应用误认为 Codex 桌面应用。桌宠已开时沿用防多开机制，手动退出后在同一次 Codex 运行期间不会重新拉起。关闭 Codex 不会自动关闭桌宠。移动或删除本目录前应先关闭此选项。

## 显示规则

- 没有运行中的本机任务：显示 5 小时和每周剩余百分比，以及今日本机token。
- 本机任务运行中：优先显示当前会话最新一条请求，过滤附件列表和应用环境信息；没有可识别请求时回退到会话标题。另显示思考／工作状态和并行会话数量。同一会话的多份日志按会话 ID 合并，采用最新任务状态，避免重复计数或旧副本误报运行。 工作卡片同时显示当前会话日志中的模型和思考强度；缺失时显示“未记录”，不猜测设置。
- 可识别的输入请求、审批请求：优先显示需要确认；需要在 Codex 主应用处理。
- 本机 Codex 有未读会话、未读收件箱消息或待回答的异步提问：切换递信姿势和加粗明亮的金色发光边框，柔和渐变高光缓慢掠过金框，每 6 秒完成一次变化，没有硬边亮段。提示边框独立于面板不透明度，透明面板上仍保持明亮；关闭动画或系统动画时保留静态金框，隐藏桌宠时暂停流光。显示待处理数量和该会话最新请求；任务完成后的未读提醒也沿用最新请求，没有可识别请求时回退到会话标题。即使平时收起面板，提醒时也会临时显示；在 Codex 中处理后自动恢复工作／用量状态。
- 任务结束：恢复用量卡片。最近的明确错误事件短暂显示出错状态。

右键菜单的“角色大小”滑块替代原有小／中／大档位。范围为初版角色的 40%–100%，每次调整 5%，默认 60%，已有大小设置保留。拖动即时生效并立即保存；与字号、面板透明度独立。50%／60%／75% 对应此前小／中／大，角色框约 106 × 147、127 × 176、159 × 221 个逻辑像素。调大时会保持窗口在屏幕工作区内。

右键菜单顶部提供字号滑块，范围 10–18，按 1 递增，默认 12。正文、时间、数值、标题和菜单使用所选字号，调整即时生效并立即保存到 `runtime/settings.json`。角色大小独立于字号；卡片宽度随字号调整，高度随当前内容自动收缩，角色紧挨面板下缘；收起面板时也收起占位空白。

字号滑块下方提供“面板不透明度”滑块，范围 20%–100%，按 5% 递增，默认 95%。100% 完全不透明，20% 更透明。卡片背景、普通边框和文字一起改变透明度；消息提醒的金色边框始终清晰，角色和右键菜单保持清晰。拖动即时生效并立即保存，下次启动沿用设置。

已启用 Per-Monitor V2 DPI 和 WPF 随监视器 DPI 变化缩放：1080p、1440p（2K）、2160p（4K）沿用 Windows“显示缩放”，不按分辨率盲目乘倍率。字号是 96 DPI 下的逻辑像素；例如选择 12，系统 150% 时实际绘制约 18 像素。选择不同角色档位不会改变字号。已做 100%／150%／200% 渲染验证，跨实际不同 DPI 屏幕的拖动尚未实机验证。

空闲卡片直接显示两项额度各自的下一次刷新（恢复／重置）时间，使用北京时间 `MM-dd HH:mm`。这些时间来自服务器 `resetsAt`；它们与每 60 秒查询一次读数的刷新频率不同。刷新时间下方追加倒计时：5 小时额度显示“5小时剩余时间：x小时x分”，每周额度显示“每周剩余时间：x天x小时”。按服务器重置时间和当前时间计算，每秒更新；不足显示单位的部分舍去，过期归零，时间未知显示 `--`。

空闲时角色左手自然放下；工作、思考时换成托腮思考姿势，脑袋旁显示问号；有消息或提问待处理时，双臂伸出递信，旁边显示红心。三种姿势使用独立透明 PNG，问号和红心随角色大小缩放，配合轻微呼吸和上下浮动动画。

空闲面板还显示套餐到期日、剩余天数和重置卡数量。到期日通过右键菜单的日期选择器手动设置／清除，保存在本机设置中；当前 Codex 账户接口未提供订阅到期日，不能自动确认续订或取消情况。剩余天数按北京时间日期差计算，当天显示“今天到期”，过去显示“已到期”。重置卡数量每 60 秒从 `account/rateLimits/read` 的 `rateLimitResetCredits.availableCount` 自动读取；未知或连接失败显示 `--`，明确的零显示 0 张。不会兑换重置卡。

## 数据口径与限制

额度和账户当日用量每 60 秒在独立后台线程通过当前 Codex 的 `account/rateLimits/read` 与 `account/usage/read` 只读接口查询，不阻塞任务状态刷新。不会调用模型或发送聊天。网络失败后从 1 分钟开始指数退避，最长 15 分钟，并加入随机延迟；成功后恢复每 60 秒查询。明确的认证／访问拒绝错误会暂停账户查询，确认登录与访问权限后重启桌宠恢复；不支持的用量接口在本次运行内停用。若接口暂不可用，退回会话记录里的最近读数，并标记旧数据；已过重置时间的旧读数显示 `--`。

`runtime/state.json` 的 `lastAccountError`、`lastUsageError` 保存最近错误的接口名称、类别、数字代码与时间，不保存服务端原始错误文本、认证信息或请求内容；`accountPaused` 和 `accountNextRetryAt` 表示暂停状态与下次查询时间。成功恢复会在对应错误记录上添加 `resolvedAt`。

需要排除额外账户连接的影响时，先退出已有桌宠，再以纯本地模式启动（不会启动 Codex app-server，仍显示本机任务、token 和日志中的额度）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\pet.ps1 -LocalOnly
```

今日本机token 是北京时间 00:00 到现在，本机可读取的 Codex 活跃／归档会话日志中的 token。按 response ID 去重，避免分叉或重复日志多算；包含缓存输入，输出已含推理，不重复累加。旧日志使用累计值差分。无法覆盖别的设备、未落盘或已删除的会话、没有 token 日志的云端对话，不代表所有 ChatGPT 聊天用量。

没有 response ID 的旧记录与新格式混用时，通过迁移边界和明确镜像快照去重，无法保证任意历史混合日志都能完全对应。增量扫描通过文件身份、修改时间和头尾锚点检测正常的替换／重写。

悬停卡片可查看缓存／输出明细、额度刷新与重置时间，以及 `account/usage/read` 返回的账户当日 token。后者采用服务端日期口径，时区和同步延迟未经确认，因此与北京时间本机统计分开显示。

任务状态每 1 秒从本机日志推断，界面每 250 毫秒检查一次采集结果，属于配套组件的状态显示，不复用或修改官方桌宠活动托盘。工作摘要来自最近的用户请求，仅显示最多 180 字的简短内容；过滤应用环境信息、附件列表和结构化提问回答。摘要与任务标题只保存在本机 runtime，发布预览使用演示数据。部分审批、异步等待和错误可能未写入日志，不能保证完整复现原生状态；长时间没新事件会提示查看应用。进程异常或强退留下的开始事件可能暂时被认为仍在工作。云端和其他设备的实时状态不在监测范围内。

消息提醒每 1 秒在独立后台线程通过本机 Codex 应用工具命名管道调用只读 `list_threads`，使用当前侧栏的明确 `isUnread` 状态覆盖旧文件标记；不标记已读、不回答提问、不发送聊天，也不改变账户查询频率。每次读取最多 50 个最近未固定聊天和全部固定聊天，仅使用本机 Codex 会话的 ID 与已读标记，不保存返回的聊天正文或摘要。响应未覆盖的会话仍为未知，保留旧存储作为补充；读取失败保留最近观察及时间戳，旧已读确认不会隐藏随后产生的新输出。真实提问和审批独立保留。`runtime/state.json` 中的 `desktopStateConnected` 和 `desktopStateUpdatedAt` 用于诊断本机连接。内部子代理排除、运行中普通未读延后提醒及模型／思考强度显示保留。

未读状态通道属于 Codex 内部接口，已验证未读／已读切换能自动改变递信提醒。需要单个正在运行的 Codex 实例及至少一个现有未归档用户聊天作为只读工具调用上下文；优先使用桌宠目录对应的聊天，否则采用最近的用户聊天，排除内部子代理。Codex 更新、通道不可用、多实例或超出最近聊天范围时，旧存储仍可能与界面不一致，悬停卡片会提示读取不完整。

除 Codex 官方只读查询外，不建立第三方网络连接，不提取或保存密钥。当前已有登录态由 Codex app-server 使用；其运行会使用正常的应用缓存目录。桌宠只在自身 `runtime/` 写入状态和设置文件。
